01 Training Phase train() ›

Reads spam.csv and learns patterns by analyzing word frequencies across spam and ham emails to identify distinguishing keywords.

Steps
1
Load Dataset
Each row → (label, email_text) where label ∈ {spam, ham}
2
Separate Texts
Split into spam_texts and ham_texts lists
3
Word Frequency
collections.Counter counts words per category
4
Find Keywords
Words appearing ≥ 8× in spam with SpamRatio ≥ 5
Spam Ratio Formula
SpamRatio = c / spam_count(ham_count / ham_total) + 0.005 ≥ 5
Example Keywords Learned
free win prize offer click urgent cash winner claim
02 Feature Extraction raw_features() / extract_features() ›

Each email is converted into 5 numerical features, all normalized to the 0–1 range.

Features
FeatureDescription
spam_kw_scoreRatio of spam keywords in message
uppercase_ratioPercentage of uppercase letters
exclamation_densityNumber of ! marks per word
digit_ratioPercentage of digit characters
url_scoreNumber of links detected
Example

03 Threshold Learning ›

For each feature, percentile boundaries are derived separately from ham and spam training emails to define fuzzy decision zones.

SourcePercentiles Computed
Ham emailsham_p75   ham_p90
Spam emailsspam_p10   spam_p25
Example — uppercase_ratio
// Ham zone (safe) ham_p75 = 0.05 ham_p90 = 0.08 // Spam zone (suspicious) spam_p10 = 0.10 spam_p25 = 0.18

05 Fuzzy Rules ›

Rules encode human-like reasoning. Multiple antecedents are combined with AND to determine the spam probability output.

🟢 HAM RULES
IF kw=LOW AND upper=LOW
   AND excl=LOW
→ HAM

IF kw=LOW AND url=LOW
→ HAM
🔴 SPAM RULES
IF kw=HIGH
→ SPAM

IF kw=HIGH AND url=HIGH
→ SPAM

IF upper=HIGH AND excl=HIGH
   AND url=HIGH
→ SPAM
06 Classification Pipeline classify() ›

When a user pastes an email, the system runs a complete fuzzy inference pipeline to produce a spam_score from 0–100.

①
Extract Features
Compute 5 numerical signals from raw email text
②
Feed into Fuzzy System
sim.input[feature] = value for each feature
③
Fuzzification
Map crisp values to fuzzy membership degrees
④
Rule Evaluation
Apply AND/OR operators across all fuzzy rules
⑤
Aggregation
Combine outputs of all triggered rules
⑥
Defuzzification
Centroid method → spam_score (0–100)
